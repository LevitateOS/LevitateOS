AcornOS Live - Install Guide
============================

This guide sits beside a root shell.
The screen's bottom line lists its
keys; in the guide, arrows scroll
and q closes it.

The steps below install AcornOS to a whole
disk, erasing it. Run them in the left pane.

1. Pick the target disk
   recpart list-disks
   Or run disk-plan: it does steps 1 and 2
   interactively, with recpart's checks.

2. Partition, format and mount it at /mnt
   AcornOS installs two system slots, A
   and B, so an update can be tried and
   rolled back. Preview first (changes
   nothing):
     recpart apply --disk /dev/sdX \
       --mode ab --dry-run
   Then apply (ERASES THE DISK):
     recpart apply --disk /dev/sdX \
       --mode ab --confirm DESTROY
   Slot A is mounted at /mnt and the state
   partition at /mnt/var. Note the slot A
   and slot B devices it reports (for
   example /dev/sdX2 and /dev/sdX3).

3. Extract AcornOS
   recstrap /mnt

4. Generate fstab
   recfstab /mnt >> /mnt/etc/fstab

5. Inspect and configure the installed system
   Stay in the live shell:
     recsetup inspect --root /mnt --json
     recsetup apply --root /mnt --hostname acornos
   Recipe supplies OpenRC, wired DHCP,
   locale defaults, and the doas wheel rule.
   Its installed setup program applies
   your machine's choices.

6. Install systemd-boot and the A/B layout
   Use the slot devices from recpart:
     recsetup apply --root /mnt --boot ab \
       --slot-a /dev/sdX2 --slot-b /dev/sdX3 \
       --machine-id
   This uses the live media's kernel,
   without an initramfs. recab writes slot
   entries and enables its packaged trial
   service for healthy-boot commit and
   rollback.

7. Set the root password
   The installed root account starts locked:
     recchroot /mnt -- passwd
   Live-session autologin stays on the ISO.

8. Reboot into AcornOS
   reboot
   Remove the install media when the
   machine restarts.

Updating later
--------------
From a new release's ISO, mounted at /mnt:
  recab stage \
    --rootfs /mnt/live/filesystem.erofs \
    --kernel /mnt/boot/vmlinuz
  recab set-next B
  reboot
The update is kept if it boots healthy;
otherwise AcornOS returns to slot A.
recab rollback goes back later.

Troubleshooting
---------------
recpart refuses the disk: it prints why;
  --dry-run shows the same checks.
No network: check ip addr; dhcpcd starts
  at boot on wired interfaces.
